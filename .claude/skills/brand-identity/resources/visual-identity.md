# ClearFlow: Visual Identity ("ClearFlow Transformation")

Image direction for marketing visuals. When a channel supports visuals, write an **English prompt** for an AI image generator using the rules below.

## Core Concept

Every image focuses on **the moment when physical chaos becomes clean, automated digital order**.

## Visual Style

- **Yes:** Cinematic, dynamic photo, shallow depth of field, natural focused lighting, a specific moment of transformation
- **No:** glowing neon, generic sci-fi robots, 3D cartoon hands, generic smiling people at desks

## Fixed Elements

1. **Chaos vortex:** papers, cables, physical mess dissolving and becoming a clean flowchart or dashboard integrated into a desk
2. **Flowchart:** A to B to C to D, sharp, logical, correct (not reversed), with data visualizations (graphs, completion bars)
3. **Brand colors:** deep navy `#1E3A5F` and slate `#4A6FA5` in clean areas, amber `#F59E0B` as accent on data points, dark elegant background (see `design-tokens.json`)
4. **Logo:** "ClearFlow", subtle and clear on the dashboard
5. **Human element:** one natural hand only, pointing at an amber-highlighted node

## Visual Strategy by Channel

| Channel | Visual | Prompt type |
|---|---|---|
| Landing page / Ads | Default: full transformation | Full scene |
| Social | Variants: close-up dashboard, before/after split, hand + node detail | Focused variation |
| Blog | Hero image adapted to the topic in ClearFlow style | Topic-adapted |
| Email | Minimal header strip in brand colors | Minimal |
| WhatsApp / SMS | Not required | None |
